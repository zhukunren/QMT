# Report font

QmtReportSans-Regular.ttf is a static weight-400 derivative of Google's Noto Sans SC.
Source: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf

Source SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.

Licensed under SIL Open Font License 1.1; see OFL.txt. The font is bundled and subset-embedded in PDF reports; runtime downloads are unnecessary.
To regenerate: `python -m pip install fonttools` then `python scripts/prepare-report-font.py`.
